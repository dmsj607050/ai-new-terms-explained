# AI 新词别慌

普通人也能看懂的大模型时代。

本项目系统整理大模型、AI 编程、Agent、MCP、Skills、RAG、插件、工作流等 AI 新概念，用通俗语言解释它们的来源、作用、区别和使用场景。

## 为什么做这个项目？

AI 技术发展很快，新概念不断出现。

很多资料要么过于技术化，要么只解释单个名词，缺少完整脉络。普通人想了解 AI，却经常被 MCP、Agent、Skills、RAG、Function Calling、AI 编程这些词劝退。

本项目希望用普通人能理解的语言，建立一张清晰的 AI 技术地图。

## 项目定位

本项目不是单纯的技术教程，也不是某个 AI 工具的说明书。

它更像是一套 AI 时代的入门知识库，重点回答三个问题：

1. 这个概念是什么？
2. 它解决什么问题？
3. 普通人为什么要知道？

## 内容主线

大模型出现 → 聊天机器人普及 → Prompt 成为入口 → 工具调用增强能力 → 插件和 API 连接外部服务 → AI 编程工具爆发 → Agent 开始执行任务 → MCP 尝试统一连接标准 → Skills 封装专项能力 → 普通人开始搭建自己的 AI 工作流。

## 内容形式

每个主题尽量包含：

- 一篇通俗长文；
- 一份短视频脚本；
- 一组图文卡片文案；
- 一句话总结；
- 参考资料。

## 适合谁阅读？

- 普通 AI 用户；
- 学生；
- 非技术背景职场人；
- AI 编程入门者；
- 内容创作者；
- 想系统了解 AI 时代变化的人。

## 更新原则

- 尽量参考官方文档和可信资料；
- 不夸大 AI 能力；
- 不把营销话术当作技术结论；
- 保持通俗表达；
- 对过时内容及时更新。
